Профиль создан. Дальше — решать задачи. Вот весь порядок действий, он не меняется.
  1. Сверху — условие задачи. Под названием есть строка сигнатура: это точное имя функции, которую ждут тесты. Назовёшь функцию иначе — не засчитает, даже если логика верная.
  2. Снизу — редактор. Пишешь код там. Tab ставит отступ, Ctrl+↵ — проверка, Ctrl+⇧↵ — запуск.
  3. ⚡ ПРОВЕРКА — смотрит код глазами и ничего не выполняет: ищет синтаксические ошибки, отсутствующую функцию, = вместо ==, цикл без выхода. Читай лог и исправляй.
  4. ▶ ЗАПУСК — вот это настоящая проверка: код исполняется в Python 3.12 и прогоняется по тестам. Над логом появится строка 2/2 тестов пройдено: зелёная — задача решена, красная — ниже написано ожидалось: X | получено: Y.

  6. Дальше — по порядку. Пока текущая задача не решена, следующие заблокированы: это последовательность сложности. Пройденные можно переоткрывать и переписывать, засчитанное не сгорает.

▣ КАК ЭТО РАБОТАЕТ

Страница запускается простым двойным щелчком по файлу — ничего больше не нужно: ни установки, ни команд, ни настроек. Настоящий интерпретатор Python 3.12 загружается прямо в браузер и исполняет твой код на этой странице.

Единственный нюанс: код исполняется на самой странице, поэтому цикл без выхода (while True: без break) заморозит вкладку. Нажми сначала ПРОВЕРКА — она находит такой цикл по тексту кода, ничего не выполняя, и ЗАПУСК такой код просто не выполнит.

Логин нужен только чтобы вести и сохранять твою статистику — она пишется прямо на этом устройстве, в его локальном хранилище.
